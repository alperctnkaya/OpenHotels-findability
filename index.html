How to vote

You will see a query image, a photo of a hotel room or a crop showing one object in it, next to all the photos we have of that hotel. Decide whether the hotel could be identified from the query using those photos.

  • FindableAt least one hotel photo shows the same room or the same distinctive things: furniture, artwork, fixtures, layout, materials. A careful person could match them.
  • Not findableNothing in the hotel photos could be matched to the query: different rooms, only generic items, or the details needed are not visible.
  • SkipBroken image or you really cannot decide. Skips do not count and the query is never shown to you again.

Queries come in a fixed order, hardest for the model first; the goal is one vote per query. Votes that others already cast are shown above the images, and you can add yours as long as a query has fewer than three. Use the skip queries that already have votes switch to see only untouched ones, or Go to a position to continue from there. You are never shown a query you already answered. When a query has its three votes you cannot vote, but Note to admin appears so you can say, for example, that you disagree.

There is no right answer; go with your judgement in about ten seconds. Under the gallery photos the number is the model's cosine similarity to the query. My votes lists everything you answered; Previous reopens your last answer, and any answer can be changed. Keys: 1 findable, 2 not findable, S skip, N note, ← previous, Esc closes an enlarged image.
