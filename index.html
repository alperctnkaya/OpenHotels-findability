How to vote

You will see a query image, either a photo of a hotel room or a crop showing one object in it (a lamp, a bed, artwork…), next to all the photos we have of that hotel. Decide whether the hotel could be identified from the query using those photos.

  • 👍 Findable At least one hotel photo shows the same room or the same distinctive things (furniture, artwork, fixtures, layout, materials). A careful person could match them.
  • 👎 Not findable Nothing in the hotel photos could be matched to the query: different rooms, only generic items, or the details that would be needed are not visible.
  • Skip Broken image or you really cannot decide. Skips do not count.

Queries come in a fixed order, hardest first; the goal is one vote per query. If someone already voted on a query you see their votes above the images and can add yours (a query takes at most three). Tick skip queries that already have votes to see only untouched ones, or type a position to continue from there. You will never be shown a query you already answered. When a query already has its three votes you cannot vote on it, but ✉ Note to admin appears so you can say, for example, that you disagree with the votes.

There is no right answer; go with your best judgement in about ten seconds per query. Room photos and object crops are separate tabs; My votes lists everything you answered, and ← Previous lets you revisit and change an answer. Keyboard: 1 findable, 2 not findable, S skip, N note (full queries only), ← previous, Esc closes an enlarged image.

Your answers are stored under an anonymous annotator code kept in this browser, so you can stop and come back any day. The study passcode is remembered here too.
